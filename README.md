# India Merchant Data API

Reverse-engineered public data from RBI and FBIL, served as one typed REST API:
FX reference-rate time series (2000 to today), bank holidays for 34 RBI regional offices,
business-day and settlement-ETA logic. An MCP layer for Agent Studio agents follows in phase 2.

Status: in development. See [docs/PLAN.md](docs/PLAN.md).
